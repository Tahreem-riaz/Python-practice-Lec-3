# 🐍 Lecture 03 — Lists & Tuples

A personal Python learning repository containing programming exercises, practice implementations, and mini-projects developed throughout my learning journey.

This repository contains my practice work for **Lecture 03** of my Python learning journey.  
The lecture focuses on working with ordered data collections using **lists** and **tuples**, accessing and slicing elements, comparing mutability vs. immutability, and applying common built-in sequence methods.

---

## 📚 Topics Covered

### 1. Lists
* Creating Lists & Storing Mixed Data Types
* List Indexing & Element Access
* Mutability: Modifying Elements in Place
* Core Differences: Strings (Immutable) vs. Lists (Mutable)

### 2. List Slicing
* Slicing Syntax (`[start:stop:step]`)
* Positive & Negative Slicing
* Reversing Lists via Slicing (`[::-1]`)
* Sublist Extraction & Shallow Copying

### 3. List Methods
* **Adding Elements:** `.append()`, `.insert()`, `.extend()`
* **Removing Elements:** `.pop()`, `.remove()`, `.clear()`
* **Searching & Ordering:** `.sort()`, `.reverse()`, `.count()`, `.index()`, `.copy()`

### 4. Tuples
* Creating Tuples & Single-Element Tuples (`(val,)`)
* Immutability Principles & Hashability
* Tuple Indexing & Slicing
* Built-in Tuple Methods (`.count()`, `.index()`)
* Key Architectural Differences: Lists vs. Tuples

## 🚀 Mini Project

### Interactive Student Grade & Inventory Manager

`05_mini_project.py` brings together the concepts covered throughout Lecture 03.

### Concepts Applied

- Lists and tuples
- List methods such as `.append()`, `.pop()`, and `.sort()`
- Tuple unpacking
- Slicing
- User input with `input()`
- Basic data processing and statistics

### What It Does

The program uses immutable tuples for fixed record templates and mutable lists for dynamic data. It accepts user entries, processes the collected information, calculates statistics such as minimum, maximum, and average values, sorts the data, and displays the final results.
